# Guitar Tabs Site — Agent Instructions

## Назначение

Этот файл содержит обязательный краткий контекст для работы с проектом.
Подробная архитектура, схемы БД, API и описание компонентов находятся в
`docs/PROJECT.md`.

## Когда читать `docs/PROJECT.md`

Обязательно прочитай релевантные разделы `docs/PROJECT.md` перед изменением:

- базы данных или SQL-запросов;
- API-маршрутов;
- оплаты, чеков, email и Robokassa;
- загрузки, хранения или скачивания файлов;
- админ-панели и авторизации;
- структуры табов, покупок или клиентов;
- архитектуры корзины, превью и анимаций между компонентами.

Для небольших изолированных правок текста, цвета, отступа или простой анимации
читать весь `docs/PROJECT.md` не требуется.

## Проект

Каталог авторских гитарных табов на Next.js:

- платные табы добавляются в корзину, оплачиваются через Robokassa и приходят по email;
- бесплатные табы скачиваются сразу в PDF, GPX/GP5 или ZIP;
- интерфейс локализован на русский и английский;
- поддерживаются светлая и тёмная темы;
- есть отдельная админ-панель создания и публикации табов.

## Стек

- Next.js 16 App Router;
- React 19 и TypeScript;

- Radix UI / shadcn/ui;

- next-intl;
- next-themes;

## Базы данных

- `guitar_tabs_dev` — разработка;
- `guitar_tabs` — production.

Схемы баз должны оставаться одинаковыми. Никогда не изменяй production-базу без
прямого указания пользователя.

Основная таблица табов называется `"guitar-tabs"` — кавычки обязательны из-за
дефиса.

## Ключевые инварианты

- Бесплатность хранится как `price = 0`; отдельной колонки `is_free` нет.
- Платный таб должен иметь цену больше нуля.
- Для бесплатного таба MP3 не предлагается при создании.
- У таба должен быть хотя бы один файл.
- Для Guitar Pro при скачивании GPX приоритетнее GP5.
- Бесплатные файлы выдаются только для опубликованных табов.
- Каждое успешное скачивание записывается в `tab_downloads`.
- Популярность платного таба определяется покупками.
- Популярность бесплатного таба определяется скачиваниями.
- Бесплатные табы не участвуют в порогах скидок корзины.
- Подсказки о следующем уровне скидки учитывают только опубликованные платные
  табы и не предлагают добавить товар, которого нет в каталоге.
- PDF-превью показывается только для платных табов.

## Правила работы

- Сохраняй существующие пользовательские изменения в рабочем дереве.
- Перед каждым коммитом актуализируй затронутые Markdown-файлы, включая
  `docs/PROJECT.md` для изменений поведения или архитектуры.
- Не выполняй destructive Git-команды без прямого запроса.
- Не меняй схему БД молча: предоставляй SQL отдельно для dev и production.
- При добавлении пользовательского текста обновляй обе локали.
- Не смешивай `purchase_count` и количество бесплатных скачиваний.
- Не открывай прямой публичный доступ к платным файлам.
- Для новых UI-элементов сохраняй существующую форму кнопок, темы и hover-состояния.
- На touch-устройствах избегай hover-зависимого поведения.
- Учитывай `prefers-reduced-motion` для заметных анимаций.

## Проверка изменений

Минимальная проверка:

```bash
npx tsc --noEmit
npx eslint path/to/changed-file.tsx
git diff --check
```

Полный `npm run lint` сейчас захватывает минифицированный
`public/pdf.worker.min.mjs` и несколько существующих ошибок вне текущих задач.
Не считай его падение доказательством ошибки в изменённом файле — запускай
точечный ESLint и отдельно сообщай о фоновых проблемах.
